# 活動自動登錄小幫手（Windows 電腦版）

自動開啟 momo、銀行的活動頁，點「立即登錄」，並記錄結果與截圖。
**帳號、密碼、OTP、驗證碼都由你自己在瀏覽器裡輸入**，程式只負責重複點擊。

## 安裝（只需一次）
1. 安裝 Python 3.10 以上（https://www.python.org ，安裝時勾選 *Add Python to PATH*）
2. 雙擊 `start.bat` → 自動安裝套件並開啟視窗
   - 程式會優先使用 Windows 內建的 Edge，不用另外下載瀏覽器

## 使用流程
1. 按 **開瀏覽器登入** → 在跳出的 Edge 登入 momo 和各家銀行（可以開新分頁）→ 登入完成後關閉瀏覽器視窗（登入狀態會保存在 `browser-profile\`）
2. 在「新增活動」貼上活動網址，或按 **批次貼上網址** 一次貼多個
3. 按 **全部登錄**（或先選幾筆再按 **登錄選取的**）
4. 每筆活動的結果會顯示在表格中：成功／已登錄過／需要登入／找不到按鈕／待確認／錯誤
5. 按 **建立每日排程**：每天固定時間在背景自動跑一次（Windows 工作排程器，名稱 `PromoAutoRegister`）

## 找不到按鈕時
選取該活動 → 按 **設定按鈕字** → 輸入活動頁上按鈕的實際文字（例如「我要參加」）。

## 產出檔案
| 檔案 | 內容 |
|---|---|
| `campaigns.yaml` | 活動清單與按鈕文字設定 |
| `results.csv` | 每次執行的結果紀錄（可以用 Excel 開啟） |
| `screenshots\` | 每筆活動執行後的整頁截圖，可當登錄證明 |
| `browser-profile\` | 登入狀態，**請勿分享或上傳** |

## 打包成 exe（選用）
雙擊 `build_exe.bat` → 產出 `dist\活動自動登錄.exe`，把 `campaigns.yaml` 放在 exe 旁邊即可使用。

## 限制
- 登入 Session 過期，或銀行要求重新做 OTP 時，表格會顯示「需要登入」，再按一次「開瀏覽器登入」即可。
- 遇到圖形驗證碼的活動頁不會自動破解，會顯示「找不到按鈕」或「待確認」，需要手動完成。
- 每筆活動之間會間隔 3–6 秒，避免被網站判定為異常流量。
